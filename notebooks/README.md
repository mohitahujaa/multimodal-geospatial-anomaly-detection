# Notebooks Directory

Use this directory for exploratory data analysis, one-off visual inspections, and debugging raster tiles:
- `01_study_area_inspection.ipynb`: View study area bounds, OSM road networks, and land use.
- `02_sentinel2_exploration.ipynb`: Test S2 bands and NDVI/NDBI/NDWI distributions.
- `03_normality_experiments.ipynb`: Prototype statistical baseline models on sample cells.
